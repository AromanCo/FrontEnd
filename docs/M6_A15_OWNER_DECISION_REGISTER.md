Record D1 and D2 before fixing applicable gates. Resolve D3–D8 and D10–D11 before any private environment implementation is authorized. D9 applies only if authentication/OTP is in scope and requires a separate explicit activation decision. D12 is a distinct later commercial gate. The M6-A10 decision brief remains the source for the original rationale; [M6-A15 acceptance gates](M6_A15_ACCEPTANCE_GATES.md) turns approved decisions into observable tests. No historical preference, CI result, diagram, or this register substitutes for owner approval.
