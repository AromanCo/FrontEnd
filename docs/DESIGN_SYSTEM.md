# AROMAN design system

Persian and RTL are defaults at the document root. The self-hosted variable Vazirmatn Arabic subset is loaded with `font-display: swap`; Arial is fallback. Colors: ivory `#F7F2EC`, plum `#382A3D`, dark plum `#302434`, champagne `#D6AD72`, blush `#F2D5CF`, lilac `#C8AECF`, sage `#93A58A`. Cream surfaces, restrained borders, rounded cards, generous whitespace, and clear high-contrast actions support the editorial fragrance style.

`src/app/globals.css` defines color tokens, responsive typography, buttons, inputs, cards, bottle concept art, mobile Studio panels, and reduced motion behavior. `Header`, `Footer`, and `ProductCard` are reusable components. Focus indicators are visible, interactive targets are at least 48px high in primary flows, and the mobile Studio uses three distinct panels.

The bottle artwork is CSS concept art. No official logo or product photograph is asserted. The textual AROMAN wordmark is a temporary brand presentation. Supplied Figma Stage 2 screenshots were not present in the workspace; visual fidelity to them remains unverified. Existing images in the neighboring Coming Soon project were intentionally not copied as production assets.
